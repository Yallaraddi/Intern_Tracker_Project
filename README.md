# InternTrack

An internship application tracker built using HTML, CSS and Vanilla JavaScript.

## Live Demo
https://my-interntrack.netlify.app

## Features
- Dashboard
- Application management
- Search and filters
- Kanban board
- Interview calendar
- Follow-up reminders
- Analytics
- Health score
- Dark mode
- LocalStorage
- JSON export

## Tech Stack
- HTML
- CSS
- JavaScript
- LocalStorage
